ကျောင်းသားစာရင်းဇယား

ဇယားထဲတွင် ဖြည့်သွင်းထားသော အချက်အလက်အားလုံးကို ပြသထားပါတယ်။ ပြင်ဆင်ရန် “ပြင်” ကိုနှိပ်ပါ။
စဉ်အမှတ်အမည်ကျား/မ မွေးရက်အတန်းမိဘအမည် ဖုန်းနေရပ်လိပ်စာအခြေအနေလုပ်ဆောင်ချက်

ကျောင်းသားအသစ် ထည့်ရန်

ဆရာ/မများထံမှ Attendance SMS ထည့်ရန်

SMS စာသားကို အောက်က Box ထဲ ကူးထည့်ပါ။ စစ်ဆေးပြီးမှ မှတ်တမ်းသိမ်းပါ။

စာရင်းအမျိုးအစားအမည်နောက်တွင် ကျောင်းသားအမည်များကို ရေးပါ။ အမည်များကို ကော်မာ (၊ ,) သို့မဟုတ် စာကြောင်းအသစ်ဖြင့် ခွဲနိုင်ပါတယ်။

SMS စစ်ဆေးချက်

သတိပြုရန် - SMS ထဲက အမည်များကို ကျောင်းသားစာရင်းနှင့် တိုက်စစ်ပါ။ မတွေ့တဲ့အမည်များရှိလျှင် မူရင်းစာသားကို ပြန်စစ်ပြီးမှ သိမ်းပါ။

လစဉ် အစီရင်ခံစာ

မပို့ရသေးသော အတန်းစာရင်း

Backup / Restore

ကျောင်းသားစာရင်းနှင့် Attendance မှတ်တမ်းများကို JSON ဖိုင်အဖြစ် Backup သိမ်းနိုင်ပါတယ်။ ဖုန်းပြောင်းမယ်၊ Browser data ဖျက်မယ်ဆိုရင် Backup အရင်ယူပါ။

Restore လုပ်ခြင်းက ဒီဖုန်းထဲရှိ လက်ရှိစာရင်းကို Backup ဖိုင်ထဲက စာရင်းနဲ့ အစားထိုးနိုင်ပါတယ်။ Backup ဖိုင်မှန်ကန်ကြောင်း သေချာစစ်ပါ။
